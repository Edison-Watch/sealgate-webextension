# Bundled fonts

Both files are the latin subsets served by sealgate.ai, bundled so the popup
renders in the product typeface without loading anything from the network.

- `archivo-latin.woff2` - Archivo, variable weight 100-900.
  Copyright 2020 The Archivo Project Authors
  (https://github.com/Omnibus-Type/Archivo). SIL Open Font License 1.1.
- `jetbrains-mono-latin.woff2` - JetBrains Mono, variable weight 400-800.
  Copyright 2020 The JetBrains Mono Project Authors
  (https://github.com/JetBrains/JetBrainsMono). SIL Open Font License 1.1.
